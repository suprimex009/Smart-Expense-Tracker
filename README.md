# Smart Expense Tracker

A Python-based desktop application for managing personal income and expenses.

## Features
- Add income and expense transactions.
- Calculate total income, expenses and balance.
- Categorize financial transactions.
- Search and delete records.
- Save transaction data using JSON.
- Visualize expenses using pie charts.
- View monthly expenses using bar charts.

## Technologies Used
- Python
- Tkinter
- JSON
- Matplotlib

## Installation

1. Install Python.
2. Install Matplotlib:

   `pip install matplotlib`

3. Download or clone this repository.
4. Run the application:

   `python main.py`
